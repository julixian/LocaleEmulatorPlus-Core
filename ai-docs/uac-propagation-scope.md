# UAC 传播测试范围

- auth：用户要求实测当前 LEP 从普通权限程序通过 UAC 启动管理员程序时是否传播，并在弹窗中确认测试探针提权。
- in_scope：本机自编译探针、当前 Core/Loader、普通子进程、`ShellExecuteExW` 的 `runas` 与管理员清单提权路径。
- network_profile：测试全程本地；微软公开文档仅用于解释系统机制。
- 操作：提权探针记录自身令牌和区域 API 返回值，创建一个同类子进程后退出。未修改系统设置、安装目录或业务软件；未新增生产 hook。
- 后续授权：用户要求定位 Shell 提权共同入口，并比较 Win10、Win7。范围包括本机自有探针的 CDB 跟踪、系统模块副本的 IDA 分析，以及从微软官方下载的旧版 PE/PDB 静态对照。旧版更新包只解包、不安装，旧版 DLL 不在本机执行；没有附加或注入 AppInfo 服务。
